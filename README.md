🍕 Pizza Runner – SQL Case Study

This project is based on Case Study #2: Pizza Runner from the 8 Week SQL Challenge, created by Danny Ma.

🎯 Project Objective

Analyze Pizza Runner's operations using SQL to understand customer orders, pizza preferences, delivery performance, and business insights.

🛠️ Tools Used

MySQL

MySQL Workbench

📊 Database Tables

runners

customer_orders

runner_orders

pizza_names

pizza_recipes

pizza_toppings

📌 Case Study Sections

Pizza Metrics – Customer orders and pizza sales analysis.

Runner and Customer Experience – Delivery and customer experience analysis.

Ingredient Optimisation – Pizza ingredients, extras, and exclusions.

Pricing and Ratings – Revenue, pricing, and runner ratings.

Bonus DML Challenge – Database modifications and additional analysis.

💡 Key Learning Outcomes

SQL joins and aggregations

CTEs and subqueries

Window functions

Date and time analysis

Data cleaning and transformation

Business problem-solving using SQL
